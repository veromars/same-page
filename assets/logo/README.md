# p.2 로고 자산

코드로 렌더링하던 `p♥2` 워드마크(Poppins 900 + 45° 기운 하트)를
**폰트 의존성 없는 벡터 아웃라인**으로 고정한 파일 모음이다.
`p` 와 `2` 는 Poppins Black 글리프를 path 로 변환했고, 하트는 원본 SVG path 그대로다.
Poppins 가 없는 환경(메일, 키노트, 피그마, 외부 사이트)에서도 항상 같은 모양이 나온다.

## 파일

| 용도 | 파일 |
|---|---|
| 마스터(색상 상속) | `p2-logo.svg` — `fill="currentColor"`, 글자색을 따라감 |
| 단색 고정 SVG | `p2-logo-{purple\|ink\|lime\|white}.svg` |
| 정사각 여백판 SVG | `p2-mark-square-{purple\|ink\|lime\|white}.svg` (1900×1900, 앱아이콘·아바타 슬롯용) |
| 래스터(가로폭) | `p2-logo-{color}-{128\|256\|512\|1024\|2048}.png` |
| 정사각 래스터 | `p2-mark-square-{color}-{128\|256\|512\|1024}.png` |

- viewBox: `0 0 1482 1017` (가로:세로 ≈ 1.457)
- 색상: purple `#9B72CC` · ink `#2D2A2B` · lime `#E2FF74` · white `#FFFFFF`
- PNG 은 모두 배경 투명. 사이즈가 더 필요하면 SVG 를 원하는 크기로 rasterize.

## 재생성

`scripts/build-logo/` 참고 — Poppins-Black.ttf 에서 `p`/`2` 글리프를 뽑아
하트와 합성한다. 레이아웃 값(하트 위치·크기·자간)은 코드로 렌더한 원본을
픽셀 단위로 맞춘 값이다.
