Chapter 05
매칭 흐름
1.5단계 매칭 구조 (v6.1 확정)
복잡한 다단계 없이 단순하게 — 얇은 풀에서 마찰 최소화.

단계액션감정
발견블러 커버 → 탭 → 세부 프로필 읽기"한번 더 들여다볼까"
♥ 북마크글/키워드/답변 읽고 ♥ 탭 (플로팅 버튼) → "paged her" 토스트"괜찮은데, 더 알고 싶어"
매칭 성사상대도 Page her → 블러 해제"어, 이런 사람이었구나" — 첫 설렘
연결메시지창 열림 → 대화/모임 자유 선택강요 없이 자율적으로
Step 1
발견 탭 북 스택 — 블러 커버 탭 → 세부 프로필 진입 (사진 선명, 답변 공개)
Step 2
♥ 북마크 (플로팅 버튼) → "paged her" 토스트 → 라이브러리 담김 (상대 알림 없음)
명시적 패스 없음 — 북마크 안 한 프로필은 주 끝나면 자연 만료
Step 3
상대도 ♥ 북마크 → 매칭 성사
"on the same page ♥" + "어떤 인연이 될지는 두 분이 써내려가요"
이 순간 블러 해제 애니메이션 (blur 20px → 0, 0.8s)
Step 4
메시지창 열림 — p.M 선택지: 모임 함께 · 만남 제안 · 직접 대화
사진 블러 정책 (v6.1 확정)
화면블러이유
발견 탭 북 스택 커버✓ 실루엣 수준표지만 보고 pass/좋아요 막기 → 한 번 더 탭하게 유도
세부 프로필 페이지 (매칭 전/후 동일)✗ 선명하게사진·글 자유롭게 — 강조하고 싶은 걸 강조하는 구조
매칭 성사 순간커버 블러 해제 이펙트발견 탭 커버의 블러가 걷히는 애니메이션 — 이미 내부에서 볼 수 있던 사진, 커버에서 처음 선명하게 보이는 순간

사진을 강조하고 싶은 사람은 사진으로, 글로 자신을 표현하고 싶은 사람은 텍스트가 강점이 되는 구조.
p.2의 차별점은 사진 너머의 것들 — UX가 이를 자연스럽게 보여줌.
발견 탭 UX (v7 개정)
북 스택 UI (카드 겹침 구조) — 주간 3~6권, 매주 월요일 오전 7시 전달
기본 3권 + 챕터 완료 시 +1권 (Ch.1/2/3 각각, 최대 +3 = 주당 최대 6권)
보너스는 주중 즉시 언락 (다음 월요일 대기 아님)
알림: 월요일 낮 12시 리마인더 (미열람 시)

인터랙션: ♥ 북마크 전용 (v7)
Pass 버튼 제거 — ♥ 북마크만 남김
프로필 상세: 우측 하단 플로팅 ♥ 버튼 (56px 원형, 보라색, 펄스 애니메이션)
♥ 탭 시 "paged her" 토스트 메시지 (1.5초 페이드아웃)
북마크 안 한 프로필 → 주 끝나면 자연 만료 → 다시보기 탭으로 이동 (v7.1: 8주 쿨다운 후 재배달 풀 재진입)

소진 후 화면:
"다음 월요일에 새로운 프로필북이 도착해요" + 날짜 표시
이번 주 프로필북 다시보기 목록 제공

필터 (v7 추가):
발견 탭 헤더에 필터 아이콘 → 바텀시트 패널

N ≥ k(주당 소비량) × W(재등장 쿨다운 주수) + 1
예: k=4권/주, W=8주 → N≥33명 → 활성 보정(÷0.6) → 고갈 버퍼(+25%) 적용 시 세그먼트당 약 65~70명 목표

지역(수도권/그 외)을 1차 세그먼트 기준으로 삼고, 나이·성향은 필터 유연성으로 흡수 — 세그먼트 조합을 전부 정밀 계산하지 않음.
장기적으로는 가입 시점에 반경 내 세그먼트 인원을 자동 계산해 지역별로 발견 탭을 순차 오픈하는 로직화를 검토.
